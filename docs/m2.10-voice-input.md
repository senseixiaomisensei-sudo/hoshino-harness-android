# m2.10 语音输入（按住说话）

移植并超越 Mika 0.1.28 的语音输入。出处与文件清单见 `THIRD_PARTY_NOTICES.md`「语音输入」一节。

## 用户能做什么

- **对话输入栏按住麦克风说话**：边说边出字（手机自带识别逐字；服务商模型按停顿分段、每段一转好就出字）。上滑取消。
  - 任务没在跑：松手后字接在输入框后面，可以再改。
  - 任务在跑：松手即**插话**，走 dsh 原生 `session/prompt mode=steer`（与排队消息「插话」同一条路，内核没收下时按 `SteerState.Deferred` 排到下一条）。
  - 任务在跑时整句只说「停 / 停止 / 别做了 / stop」：按**停止**处理（与停止按钮同一条路）。
- **设置 › 模型 › 语音转文字**：独立于对话/子代理/压缩/视觉的一种用途。可选自动、手机自带、不用，或任一 OpenAI 兼容服务商的模型（列表里像语音模型的会列出，没有的可手填）。
  - 选模型时用约 1.2 秒内置合成音频（代码生成，非录音素材）试转，依次探测：`/audio/transcriptions` → Gemini 原生 `generateContent`（谷歌地址）→ 对话接口 `input_audio` 裸 base64 + 指令 → data URI + 指令 → 只发音频。通了才选上并**记住写法**。
  - 记住的写法以后失灵（404/400/格式不对）会自动重新探测一次并记住新写法；Key、额度、网络问题不重探。
  - `language` 参数被网关拒绝（400/422）时去掉语言再转一次。
- **悬浮胶囊长按说话**：长按悬浮球开始，出现听写卡片和「改一改」「取消」两个落点；松在落点外＝发给此刻对着的那件事（有待回答的问题就回答，任务在跑就插话/停止，否则作为新消息）；拖到「改一改」打开面板把字放进输入框；拖到「取消」丢掉。
  - 听写卡片是不可触摸的浮层（`FLAG_NOT_TOUCHABLE`），不挡后台屏预览和接管操作，不拿焦点，只在默认屏上画、不进入 Agent 的虚拟屏。
  - 胶囊被收起（进入 Hoshino、打开应用内虚拟屏、锁屏）或换成「你来处理」时，说到一半的话直接丢掉、麦克风放开。
  - 麦克风同一时刻只给一处（`MicGate`）：输入栏和胶囊不会同时录音。

## 稳健性

| 情况 | 处理 |
|---|---|
| 手机自带识别 3 秒没有任何回调 | 报「3 秒没有响应」并指去设置；连着 2 次才把这台手机记成不响应，重新选它会清掉 |
| 服务商松开后 3 秒还没转完 | 卡片显示「转写有点慢」，最多等到 30 秒 |
| 开始 3 秒麦克风送来的全是 0 | 提示「麦克风没有声音：可能被别的 App 占用或被静音」 |
| 单段 30 秒上限 | 服务商路按停顿切段，单段到 30 秒硬切并提示；每段转写请求最多等 30 秒，超时报网络不通；一次按住最长 2 分钟 |
| 全是安静的段 | 不送服务商（省额度，也避免模型对静音编出字） |
| 某段失败、别的段有字 | 按已转出的字收尾，不整句丢掉 |
| 语言标签 | `zh-Hans-CN`/`zh_CN` → `zh-CN`，`zh-Hant` → `zh-TW`，`iw` → `he`，扩展去掉；转写接口只传 ISO-639 语言码 |
| 麦克风权限 | 第一次按住时才申请；拒绝时提示，勾了「不再询问」时弹窗指去系统设置；胶囊没有权限时提示先在输入栏授权 |

## 离线转写

只预留接口：`SpeechChoice.Offline` 能存能读，解析为「未安装」。本批不引入模型或引擎；将来只用开源模型（如 sherpa-onnx + SenseVoice）。

## 结构

- `core-bridge/.../voice/`（纯 JVM，`ArchitectureGuardTest` 把它列为纯逻辑包）：选择与解析、会话事件、`HoldToTalk` 状态机、`ProviderSpeech` 分段转写、`Transcriber`、`Wav`、`SpeechLang`、`SystemSpeechRules`、`VoiceRouting`、`MicGate`、`CapsuleAim`。
- `app/.../voice/`：`PcmRecorder`（AudioRecord）、`SystemSpeechSession`（SpeechRecognizer）、`VoiceInput`（入口与设置存取）、`VoiceCopy`（文案）。
- 界面：`ui/chat/VoiceHold.kt`（麦克风按钮、听写卡片、权限）、`ui/settings/SpeechScreens.kt`、`phone/CapsuleVoice.kt`。
- 不加任何闭源依赖、Google Play Services、ML Kit；手机自带识别走系统 `android.speech.SpeechRecognizer`（清单声明查询 `RecognitionService`）。录音只在按住时进行，不保存；日志不含 Key 与录音内容。
