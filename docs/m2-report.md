# Hoshino Harness M2 实施与交付记录

2026-10-27。版本 `0.2.0-m2`，versionCode `200`，applicationId `dev.hoshino.app`。构建只在 GitHub Actions 标准 Linux runner 执行；本机仅运行 TypeScript 编译、针对性回归、哈希/证书检查。

本报告按实际证据区分实现、验证和未完成项，不把编译通过当作整份 M2 验收通过。

## 已实现

- 原 ZIP Compose 导航、品牌和组件保留。每个对话轮次归为一个过程组，默认折叠，最终回复、审批/提问和交付文件卡独立显示；支持按类型/当前步展开、长输出选择复制与查看全部，移除强制流式滚动。
- UI Schema、slot 解释器、绑定/事件、动态页面、侧栏图标网格、主题颜色/字号、局部动画与受限本地面板。非法 slot 单独降级，公开配置通过 Schema 验证后写入。
- `@hh/bridge` 版本 1 SDK；原 loopback 会话/鉴权边界保留，增加文件交付/保存/分享、电量、通知、快捷方式、Intent、WebView 渲染等 Android 能力。
- 普通文件形式的模式、系统提示词、审批、路由、搜索、UI、插件和技能；变更热重载。新增 self_read/write/diff/apply/snapshot/rollback/doctor/build/update，保留原 self 工具。
- 四档审批、规则组合、作用域覆盖、高危确认开关、审批模型超时/失败回退、无参数/无凭据的审计记录；通知允许/拒绝/本会话允许与文字回复。
- 九种模式、工具白名单、只读限制、温度/步数/输出预算、模型备用路由；原版 dsh Goal、子代理、待办和定时服务通过 boot 组合加载，没有 fork Agent loop。
- 分层提示词追加/替换、变量、JSON 模板存储、来源预览；工具协议单独保留。预览 token 数明确为估算。
- 无 Key 搜索与多源故障切换，中文查询优先中文源，公共 SearXNG 实例发现；正文/链接提取、PDF 按需工具、WebView DOM/截图与脚本交互。默认遵循 Android 网络/VPN。
- npm/git/local/tgz 插件安装、Cordis 配置导入、GitHub 公共配置同步、npm 搜索；插件加载失败隔离并返回原因。
- 按需下载媒体/文档/语音/编译工具；原生文件卡、音视频/图片/PDF/ZIP/DOCX 文本预览、流式保存/分享。大附件流式导入上限 1 GiB。
- 源码工作副本、GitHub 分支/构建/产物轮询、SHA256/包名/证书校验、Shizuku 包管理安装与系统确认回退；源码构建递增版本号，保留三个旧 APK。安全模式、配置快照、UI/会话偏好持久化、备份与原生恢复入口。
- 前台服务通知、暂停/停止、事件恢复、后台定时唤醒/WorkManager、系统分享入口、语音输入、快捷磁贴和桌面小组件。

## 验证

本地实际原版 dsh 集成覆盖双模型协议、流式/推理、write/read、todo、设备与系统桥、上下文、搜索、凭据不落盘，以及模拟 GitHub 的源码提交→构建→匹配产物→安装桥。Windows 不运行 Linux bash 用例，Ubuntu CI 额外执行它。

聚焦回归覆盖 UI Schema 的具体错误路径、四种审批、规则作用域、高危开关、真实计时的审批模型超时、保留最后有效配置、流式 ZIP、快照恢复与搜索故障切换。保留八项 M1 仪器回归，增加 M2 slot 热重载/局部降级与文件交付、10 秒媒体/DOCX/ZIP 生成检查。30 分钟后台观测在独立 AOSP 模拟器执行，不进行压力测试。

最新通过/失败、APK SHA256、大小、性能和后台观测以交付时补入的 CI 记录与 `m2-metrics.json` 为准。arm64/OEM 真机没有现场连接，不填写假数据。

## 明确未完成或尚未完整验证

- 没有完成文档全部九项端到端验收及真机签认，因此不能称整份 M2 全量验收通过。
- 本地 arm64 JDK/SDK/aapt2 下载构建包未交付；默认 GitHub 远程构建链已实现。
- DSL 不是全部原有组件/Token 的无损替身；原界面的全部圆角/间距/字体族/动效曲线尚未全部改为全局可变 Token。受限面板桥目前只开放电量/版本。
- 配置扫码导入、桌面 GUI/特定路径的通用兼容映射、原生模块自动编译重试和市场完整兼容性判定未全部完成。十个插件的实际验证层次见兼容表，不能把 boot 成功写成安装并调用全部通过。
- 小模型标题/压缩与视觉模型的完整自动路由、提示词模板的独立可视化库、原始请求逐字比对页面仍有缺口。路由 JSON 可编辑不等于每一辅助调用都已使用它。
- HTML 正文提取采用启发式，不是完整 Mozilla Readability；显式 HTTP/SOCKS5 代理配置尚未实现，Android VPN/系统网络继续生效。图片批量下载/分页抓取仍需工具脚本组合。
- 工作区快照恢复保守保留快照之后新增的文件，不会删除并行用户工作；这不等于完整事务级“撤销本轮”。编辑已发送消息后重新生成、原生完整 Git/PR 面板、估算费用和任务预算 UI 尚未全部接通。
- Android 强制停止后系统不会自主重启应用；必须重新打开。OEM 后台白名单、安装/回滚与运行中强杀恢复仍需真机验收。没有把模拟器存活率写成小米/华为等厂商保证。

## 失败记录

- 首轮远端构建修正 Compose 组件参数；后续修正本地函数语法和 Shizuku 跨模块引用。
- 固定 x86 Node APK 在滚动镜像消失，改为复用已验证 musl/native 基座并只补锁定的 JS 依赖，未更改 dsh 版本或混入 Windows/glibc 原生模块。
- 一次构建生成 APK 后，证书门槛拒绝 runner 默认密钥 `6d0c…90aa`；未发布该包。原密钥证书 `e20b…8fd1` 仍在，已显式指定 debug store 路径。

## M3 建议

优先补齐上述未完成项，先做真机启动/后台/安装恢复矩阵，再扩充 Token/slot 覆盖、原生模块兼容和完整时间旅行。保持原版 dsh 与既有业务边界，避免继续增加并行内核。
