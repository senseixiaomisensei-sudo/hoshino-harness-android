# m2.9 悬浮球：虚拟屏预览、无极缩放、手动接管、可调帧率

用户需求：「先增加悬浮球可以看虚拟屏幕以及当前进程，增加虚拟屏幕可以无极调节大小以及手动接管」；追加：「虚拟屏帧数可在设置里调，最高 60 fps，默认 30」。

## 做了什么
- **悬浮球**（`PhoneCapsule.kt`，替换原胶囊卡片）：保留 m2.8.1 的去抖（`CapsuleVisibility`）与任务期常驻；点开为悬浮面板：后台屏实时画面 + 当前步骤、最近几步、任务状态/耗时、停止；审批/提问/AI 请求接管/插话照旧。收起回小球，小球可拖动吸边，面板拖标题栏移动。显示状态机在 `BallPanelModel`（接管中不能收起；面板收起即停止渲染）。
- **无极缩放**：拖右下角把手或双指捏合连续调整，保持纵横比（`PreviewGeometry`），尺寸与位置持久化（`phone_capsule` prefs：`previewW`/`panelX`/`panelY`）。
- **手动接管**（`ManualTakeover` + `PhoneController.gated` / `GuardedPort.perform`）：面板「接管」后 AI 的每个手机动作在闸门处等待（最长 10 分钟，超时什么都不做并返回 `user_takeover` 错误）；用户在预览上的点按/长按/滑动按比例映射成后台屏像素，走助手现有 `injectTap` / `injectStroke` / `injectKey` / `injectText`（中文走 `setClipText`+Ctrl+V+`restoreClip`）；「交还」后等待中的动作继续：一批步骤若在接管中等待过则整批不执行（ref 已过期），返回最新画面 + `user_takeover` 一句摘要（时长、各类操作次数、前台 App 变化，不含用户输入的文字）。无 AIDL 改动。
- **帧率设置**（`FpsMath` + `PhoneDisplayFps`，设置 → 设置手机操作 → 虚拟屏帧率）：5–60，步长 5，默认 30；有人看时采集节流（`AgentDisplay` 原 `FRAME_INTERVAL_MS`）与预览渲染都按此值；没人看时不画预览，采集最多 10 fps（等于改动前的节奏，OCR/截图/WP-1 帧签名按它调过）。
- **零拷贝预览**（`PreviewRelay.kt`，实验开关，默认关）：VirtualDisplay → SurfaceTexture（GL 线程）→ GPU blit 到 ImageReader（按采集频率，CPU 侧消费者不变）和面板 TextureView（按预览频率，仅面板打开时）。EGL 失败自动回退到 Bitmap 预览。因发版时间未经真机验证，默认关闭；默认路径为 Bitmap 预览（宽 360，按用户帧率）。
