## 2. 设置向导（PH22，PL3）

- [ ] 设置 → 权限与系统 →「设置手机操作」能打开；离开页面（稍后再说）不报错。
- [ ] **同意页所有项默认不勾**；「自动打开无线调试」在没勾「WRITE_SECURE_SETTINGS」时不可勾。
- [ ] 不点「保存并应用」之前：`adb shell settings get secure enabled_accessibility_services` 不含 Hoshino；`dumpsys deviceidle whitelist` 不含 `dev.hoshino.app`；`dumpsys package dev.hoshino.app | grep WRITE_SECURE` 未授予。
- [ ] 只勾「自动开启无障碍」并保存 → 配对后无障碍被打开；其他两项仍未执行（同上命令核对）。
- [ ] `files/phone-audit.log`（「复制诊断」里能看到末尾 20 行）记录了每一次自动改动，且没有任何屏幕内容。
- [ ] HyperOS 提示 6 条都能看到；按提示打开「USB 调试（安全设置）」。
- [ ] 「复制诊断」复制出的 JSON 只有包名与开关状态，没有屏幕文字。

## 3. 配对与助手（PH2）

- [ ] 「开始配对」→ 跳到无线调试 → 点「使用配对码配对设备」：无障碍已开时**自动读出配对码并配对**（读码不写日志）；未开时弹带输入框的通知，在通知里填码能配对。
- [ ] 填错码：通知提示「配对码不对」，输入框还在。
- [ ] 首次配对耗时（含找端口）：____ s（门槛中位 ≤ 60 s）。
- [ ] 配对后状态「助手运行中」；杀掉 Hoshino 进程再打开，3 s 内助手重新交接（不需要重新配对）。
- [ ] 重启手机：未勾「自动打开无线调试」时，**无线调试保持关闭**，向导显示「无线调试关着」；勾选后连上 Wi-Fi 自动打开一次并发一条静默通知「已自动打开无线调试」，审计日志有一行。
- [ ] 若已安装并授权 Shizuku：手机助手走 Shizuku（向导第 3 步显示「通过 Shizuku 运行」）。

## 4. 后台屏与读屏（PH1、PH3、PH4、PH25、PH27）

- [ ] 让 Agent「打开设置看一下电池电量」：主屏不切换，你可以继续用别的 App；对话页右上角出现小画面（绿边）。
- [ ] Android 14+：后台屏打字时你在主屏的输入不丢字（输入 200 字，丢字数：____）。
- [ ] 建屏耗时 ____ ms（门槛 ≤ 800 ms，`phone_status` 前后计时）。
- [ ] `phone_observe` 返回压缩元素列表，再次读取只返回变化（refs 不变）；滚动后显示 `scrolled content shifted by`。
- [ ] 自绘界面（如某些游戏/小程序页）：树很薄时自动用 OCR 补字（结果头部带 `· ocr`）；未下载模型时不报错、只是没有 OCR 元素。
- [ ] OCR 整屏耗时 P50：____ ms（门槛 ≤ 350 ms；沙盒 JVM 4 线程实测约 1.0 s，真机待测）。
- [ ] 防截屏页（银行/支付类）：`phone_screenshot` 返回 secure；`phone_observe` 标 `secure`，不做 OCR；Agent 改用 `phone_handoff`。
- [ ] OCR 运行时抓包：0 个出站连接（只有点「下载模型」时访问 huggingface.co）。

## 5. 动作、输入与效果（PH5、PH8、PH9、RT13、RT14、AP7）

- [ ] tap / long_press / scroll / swipe / back / press_key / launch_app 各执行一次成功。
- [ ] 输入：普通输入框走 `set_text`；网页编辑器类走 `paste`，粘贴后你的剪贴板内容恢复原样（字节比对）。
- [ ] 没有焦点框时 `type` 返回 `no_focus`；密码框拒绝输入并提示交给你。
- [ ] 点空白处返回 `effect: no_effect`；切到别的 App 返回 `place_changed`；平台提示「操作过于频繁」时返回 `limit_reached`。
- [ ] 锁屏后让 Agent 继续：动作 0 次执行，返回 `locked`。
- [ ] 让 Agent 打开 Hoshino 或点 Hoshino 的界面：被拒绝（`own_app`）；同意页勾「允许操作 Hoshino 自己」后才放行。
- [ ] 30 分钟后台任务不被 Doze 打断（任务期间持有 PARTIAL_WAKE_LOCK，电池白名单需用户同意）。

## 6. 审批（AP、默认手动不放松）

- [ ] 默认审批（manual）下，第一个 phone_* 工具弹审批卡；选「本会话总是允许」后，同一会话的其它 phone_* 工具不再问。
- [ ] 让 Agent 在微信给文件传输助手发一句话：到「发送」这一步**单独再问一次**（卡片标题「工具执行审批」，命令 `send: tap "发送" @ com.tencent.mm`），即使之前选了「本会话总是允许」也要问；允许后只放行这一步这一屏，下一次发送仍会问。
- [ ] 拒绝后 Agent 不重试该步。
- [ ] 购物流程到付款页：Agent 不会请求审批去点付款，而是 `phone_handoff` 交给你。
- [ ] 审批模式改为 auto（用户主动开）后，不可逆步骤按用户的策略处理；`approval.json` 未改时默认仍是手动。

## 7. 接管（PH17）与静音（PH18、RT6）

- [ ] Agent 遇到登录/验证码时调用 `phone_handoff`：通知「需要你处理」有「我来处理 / 处理好了 / 跳过」。
- [ ] 点「我来处理」：App 从后台屏挪到主屏（≤ 500 ms）；处理后点「处理好了」：挪回后台屏，Agent 收到重读后的画面差异。
- [ ] 「跳过」：Agent 收到 `skipped`，不当作已完成。
- [ ] 两个接管请求排队，按顺序处理。
- [ ] 同意页勾「静音」后：后台屏 App 播放声音被静音，任务结束（或 `phone_finish`）后恢复；任务中强杀 Hoshino 再打开，助手连上后声音恢复（`appops get <pkg> PLAY_AUDIO` 与任务前一致）。

## 8. 悬浮胶囊（CU1–CU5、CU7、RT18）

- [ ] 任务运行时（Hoshino 不在前台）出现胶囊；Hoshino 在前台、锁屏、无障碍关闭时不显示。
- [ ] 3 s 后淡到 40%；拖动后松手贴边；重启后记住左右边和高度。
- [ ] 点开卡片：小画面 ≤ 5 fps、最近三步、停止按钮能停住任务（「已停止」）。
- [ ] 卡片里能完成审批（允许一次 / 本会话允许 / 拒绝），能点选 `ask_user` 的选项，输入框插话（运行中走 steer）。
- [ ] 胶囊可见时「需要你」通知静默进通知栏（静默频道）；锁屏/胶囊不在时正常弹出。
- [ ] 双击胶囊：卡片截图前胶囊隐藏，截图里没有胶囊；对话收到「此刻的屏幕」消息（含截图与压缩文字）；防截屏页只发 App 名。
- [ ] 胶囊常驻时前台 App 滚动掉帧增量：____%（门槛 ≤ 1%，`dumpsys gfxinfo` 对比）；进程内存增量：____ MB（门槛 ≤ 15 MB）。

## 9. 对话页小画面（PH24）

- [ ] 有后台屏时出现，可拖动、跨半屏换边、点按收起；需要你处理时橙色呼吸。
- [ ] 小画面开启时对话页滚动掉帧率：____%（门槛 ≤ 5%）；内存增量 ____ MB（门槛 ≤ 30 MB）。

## 10. 诊断（PH26）

- [ ] `phone_status` 一次报清：系统版本、是否有独立焦点、无障碍、助手通道、OCR、锁屏、静音中的 App、同意项；不含任何屏幕文字。

## 未在本分支实现、留给后续（不要当成失败）

- 多虚拟屏并行（RT1，m3.1）、降采样建屏、Android 10–12 主屏前台降级模式（PH1 超越项）。
- 自带输入法彻底不碰剪贴板（PH5 超越项）、胶囊里框选区域发屏（CU5 超越项）、胶囊语音插话。
- 复合工具 `phone_collect/query/find`、看图定位、系统动作 Intent、滚轮、定向分享、主屏拉回（m2.9 WP9-D1/D2）。
- Wi-Fi 白名单只在用户亲手允许过的网络上写（需要定位权限读 SSID，暂用「系统拨回即停止」代替）。
- OCR 只认整屏（未做「只认树里没字的区域」的裁剪优化），按树指纹缓存。
