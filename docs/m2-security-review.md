# M2 定向安全复核

范围仅为本次新增的原生桥、更新、公开配置、归档和本地面板；不是全库 SAST/SCA 或第三方插件审计。

| 输入 → 操作 | 已落实的边界 |
|---|---|
| Node → Android 能力 | 原鉴权 loopback 回调、桥版本检查、明确 action 分派 |
| GitHub token → API | Android Keystore；只访问配置仓库的 api.github.com；下载跳转不转发 Authorization |
| 下载 APK → 安装 | HTTPS、流式大小上限、SHA256、applicationId、安装中证书相等；保留旧 APK |
| CI 密钥 → Gradle | GitHub Secret 注入；显式 signing store；发布前固定原证书门槛 |
| self 文件 → 配置/源码 | 路径根约束、公开配置拒绝凭据、Schema 路径错误、写入前快照 |
| ZIP → 恢复 | 文件名/路径/大小预检，限定 self/home 数据子树，临时文件原子替换；拒绝运行中会话的原生恢复 |
| 本地面板 → WebView | 阻断网络、文件/内容访问与导航，CSP 禁远程脚本，仅开放电量/版本接口 |
| 审批 → 日志 | 不记录动作参数、文件内容或凭据；审批模型超时回退人类/拒绝 |

已修复：runner 默认密钥导致的覆盖签名漂移；跨模块直接依赖 Shizuku；公开配置明文密钥入口；源码文件错误路径未返回用户；安装/配置错误的脱敏展示；插件连续安装覆盖依赖清单。

可信插件仍在同一 Node 进程执行，不能把工具审批误称为恶意插件的安全沙箱。工作区快照不是并行会话的事务隔离。上述边界已在报告中明确。
