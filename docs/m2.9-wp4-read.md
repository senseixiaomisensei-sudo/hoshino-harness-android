# m2.9 WP-4（B-1）复合读工具：phone_query / phone_extract / phone_find / phone_collect

目标：长列表、聊天记录在手机端循环滚动读完、去重合并，一次返回结构化结果，不再每屏回模型。

## 工具

| 工具 | 做什么 | 是否滚动 |
|---|---|---|
| `phone_query` | 当前屏按 `text` / `id`（resource id 片段）/ `role`（btn/input/text/list/switch/tab…）/ `inside`（所在行或容器的文字）找元素；每条结果是 phone_observe 同款的元素行（ref、角色、名字、坐标、标记），附最近两层带文字的容器和所在列表行 | 否 |
| `phone_extract` | 当前屏结构化读：`mode=text`（纯文本，去掉容器已包含的子文字）、`rows`（列表行 + 行 ref）、`form`（输入框/开关 + 标签 + 值；密码框值一律 `(hidden)`）；`from_y/to_y` 限定区域 | 否 |
| `phone_find` | 在手机端滚动直到出现匹配元素（同 query 的过滤条件），内容不再移动即停，`max_scrolls` 默认 10、上限 30；返回命中元素的 ref | 是 |
| `phone_collect` | 一次读完整个列表/聊天：手机端逐屏读、对齐合并、去重，每行返回一次并带稳定 key；`direction=up` 读更早的聊天记录；`max_items` 默认 80、上限 300；`max_scrolls` 默认 15、上限 40；输出超过约 12000 字符或到 `max_items` 时返回 `cursor`，下次带上即可续读 | 是 |

返回格式：第一行一行 JSON（`ok`、`stop`、`items`、`screens`、`scrolls`、`cursor`…），后面是正文行。collect 每行是 `key 行文字`，同文重复行的 key 带 `-2`、`-3`（两条“好的”都保留）。

`stop` 取值：`found` / `end`（内容不再移动或连续两屏无新行）/ `max_scrolls` / `max_items` / `max_chars` / `needs_user` / `secure` / `app_changed` / `scroll_failed`（含原因，如 own_app、locked）/ `stopped`。

## 实现

- `app/.../phone/ScreenQueries.kt`：纯函数（JVM 单测覆盖）——参数解析与校验、`query`、`rows`、`extract`/`form`、行合并 `mergeDown`/`mergeUp`、`resume`（游标续读）；`ScreenReader` 只驱动 `PhonePort` 做滚动循环。
- 行的分组：先认列表项容器（列表区域内宽 ≥ 60% 的可点元素，用它的聚合文字），其余文字按纵向重叠分带（聊天气泡、纯文本列表）。行 key = 规范化文字（去空白、小写）的 FNV-1a 32 位十六进制。
- 跨屏对齐（比 Mika 的纯文本行序列合并多做的）：
  - 无障碍滚动通常整页滚，两屏只共享被边缘切开的那一行，且两边可见文字不同。被切行（碰到列表上/下沿）在接缝处按“一方包含另一方”匹配，并保留较完整的那份文字。
  - 一行短、两边都完整的同文行（如“好的”）在接缝处不当作重叠，按第二条消息保留。
  - 最多允许两行已读过的顶部行（如悬浮日期头）跳过再对齐；没有重叠证据时整屏追加（整页滚动下这是正常情况，不报给模型）。
  - 游标 `c1.<方向>.<最多 4 个 key>`：续读时在当前屏任意位置找这串 key，找到就从其后继续，并把这几行留作下一屏的对齐依据；一个短 key 单独出现不采信；完全找不到时从当前屏重新开始并标 `cursor_lost`。
- `PhoneController` 新 action `query/extract/find/collect`：参数先校验再碰屏幕；滚动经 `GuardedPort`（锁屏、Hoshino 自身界面等守卫每次都生效），find/collect 期间持 wake lock、胶囊显示 Working；最后一屏写回会话的 last shown，下一次 phone_observe 仍是小 diff、结果里的 ref 继续有效。
- `plugins/android-phone/read.ts`：工具 schema（全是扁平 string/number/enum 参数）与插件侧参数校验（与 Kotlin 同口径），`index.ts` 按工具追加注册。
- 其它小改：`ScreenCompressor` 截断提示原来指向不存在的 `phone_read_screen`，改为指向 phone_query / phone_collect；`ToolKinds`（运行指标）把 `extract`/`collect` 算作读；`hoshino-turn-policy` 的回读工具加上 phone_extract / phone_collect；`PHONE_PROMPT` 加一行“读取优先一次调用”。

## 审批与安全

- 与其它 phone_* 工具共用同一个会话级审批（默认手动），读工具不放宽默认审批。
- 读工具只做滚动，不会命中不可逆操作；密码框文字不进 query 结果，form 里只给 `(hidden)`；安全屏（FLAG_SECURE）返回 `stop=secure` 并提示 phone_handoff。
- 日志只记步骤种类（`action scroll pkg=… ok=…`），不记屏幕内容。
