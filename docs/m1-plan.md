# M1 执行与验收计划

本次需求来自用户提供的 M1 任务书与原生 UI ZIP；交付使用公开 APK 下载直链。只实施 M1，未接入的后续功能保留 ZIP 页面并禁用，显示“即将支持”。

1. 核对 M0 软件门槛；按 ZIP README 方式 B 合并完整 UI，保持 SessionStore 原样，生产仅使用 DshHarnessClient。内核异步启动，界面可立即输入。
2. 接通原版 dsh 会话、模型与流式事件；删除 M0 临时界面。修复系统截图与消息、代码、工具复制，API key 编辑期间临时启用窗口保护。
3. 组合原版终端与文件工具，补工作区管理、编辑与 Diff 审批；编译两个 musl ABI 的 PTY，验证超时、中断和输出限制。
4. 实现应用内截图、长图、预览、保存/分享和视觉输入；增加 Cordis android-ui 与 hoshino-self 插件，生成自述手册、技能、快照、回滚、安全模式和声明式覆盖。
5. 补聚焦测试与 M1AcceptanceTest，跑完整 CI，记录 ZIP 页面映射和截图、体积/性能/未验证项，交付两个 0.1.0-m1 APK、SHA256 和公开 Release 下载地址。

同一问题连续失败三次时改用任务书允许的另一方案，记录原因，不通过编造数据或替换原版持久化规避。arm64 真机与各厂商 ROM 仍按实测/未验证分别记录。
